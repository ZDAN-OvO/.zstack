# 任务简报：admin-console 迁 React 的路线对比（一页表）

## 背景与目的

`admin-console` 目前是 Vue 技术栈。**是否迁移尚未决定**，本次只要"有哪些路线、各自代价和风险"的横向对比，用于后续决策讨论，不产出迁移方案、不写迁移代码。

这是一次**探索型**任务：产出的是"选项 + 代价 + 风险 + 证据"，不是实施计划。

## 交付物

- 唯一产出文件：`docs/analysis/admin-console-vue-react-options.md`
- 内容 = 一张对比表 + 极短的证据缺口说明（不超过 10 行）
- **一页**的定义：Markdown 总行数 ≤ 45 行，表格列 ≤ 5 列，在 1280px 宽屏幕上一屏可见、打印为 A4 一页不溢出
- 不写代码块、不写目录结构建议、不写阶段排期表

表格行（三条路线，顺序固定）：

| 行 | 路线 |
| --- | --- |
| 1 | 全量重写（Vue → React 一次性替换） |
| 2 | 渐进迁移（新页面 React、旧页面 Vue 并存，按路由/模块切分） |
| 3 | 不迁（留在 Vue，含依赖与版本治理） |

表格列（5 列，不得增列以免超一页）：

1. `路线`
2. `做法与范围`（一两句，说明"迁什么、怎么共存/切换"）
3. `代价`（区分两类：仓库里可验证的改动面 vs. 需要假设的投入）
4. `主要风险`
5. `适用前提`（什么条件下这条路线才成立）

证据用脚注编号 `[1] [2]` 标在第 2–5 列单元格内，表格下方列脚注清单，每条脚注必须是 `相对路径:行号` 或明确标注 `假设`。

## 证据边界（关键约束）

### 允许的依据

仅限本仓库：

- `package.json`
- `src/**` 下的现有文件内容

### 禁止的依据

- 禁止联网检索，禁止引用任何框架对比文章、benchmark、社区观点、"业界普遍认为"
- 禁止编造仓库里没有的量化数据：代码行数、组件数量、页面真实数量、团队规模、人天/人月、迁移工期
- 禁止把注释当成事实

### 当前仓库实际证据（执行者应自行复核，不要直接照抄结论）

复核命令：`cat package.json && find src -type f | sort && wc -l src/**/*`

已知情况：

- `package.json`：`private: true`，4 个运行时依赖 `vue 3.4.21`、`vue-router 4.3.0`、`vuex 4.1.0`、`element-plus 2.6.1`；**无 devDependencies、无 scripts、无 React 相关依赖、无构建工具**
- `src/App.vue`：1 行，`el-config-provider` 包 `router-view`，说明 UI 库（Element Plus）在根层就介入了
- `src/router/index.js`：2 行，`export default []`，另有一行注释"40 个页面路由，此处省略"
- 仓库中**不存在**任何页面组件、store 文件、测试、lockfile

由此必须写进"证据缺口"一节的事实（这是本任务的核心判断点）：

1. **"40 个页面"只是一行注释，不是代码事实**。表格里不得把它当已知规模使用；如要引用，必须写成"注释声称约 40 个路由，未在代码中验证"。
2. 真实的改动面无法从仓库量出（没有组件文件、没有 LOC、没有测试覆盖）。因此"代价"列只能给**可验证的定性改动面**（如：Element Plus 深度耦合需整体替换、vuex 状态层需重建、路由表需重写），以及**明确标注为假设**的量级区间。
3. 仓库缺少构建配置与脚本，说明连"当前如何构建/部署"都不可知——这是三条路线共同的前置未知项，应在证据缺口里点名，而不是分配给某一条路线当风险。

如果复核后发现证据与上述不符，以实际文件为准，并在缺口说明里记录差异。

## 执行步骤

1. 复核仓库证据（上面的命令），记录实际文件清单与行数。
2. 按三条路线填表；每条路线的"代价"必须能追溯到 `package.json` 的某个依赖或 `src/` 的某处代码，否则标 `假设`。
3. 每行至少给出 1 条具体风险，且风险要来自本仓库的结构特征（例如 Element Plus 组件在模板层的渗透、vuex 与组件树的耦合、路由表作为切分边界是否可行），不要写"生态风险""人才风险"这类与仓库无关的泛论。
4. 写文件，然后按下方验收清单自检。

## 禁止事项

- 不写迁移代码、示例组件、codemod、脚手架、`npm install` 命令

- 不输出实施排期、人力分配、里程碑
- 不给出"建议立即迁移"这类结论；如确要写倾向性判断，最多一行，且必须带前提条件，并明确"本次不做决策"
