# Brief: 下季度产品方向——押"更好用"还是"更便宜"，交出可决策的一个建议

- Stage: decide
- Source: 帮我写个 brief：目标是给下季度产品方向决策（更好用 vs 更便宜）提供依据，最后要一个明确建议和理由。背景：年营收约 200 万美元的营销自动化 SaaS，客户是 50 人以下公司，常嫌复杂和贵，去年调价反响不好。素材用三家竞品官网和我整理的用户评论，不用二手评论文章，查不到就留白。不要编 ARR/用户数，不动付费等级架构。先给 outline，审过再展开。

## Goal

- 支撑下季度产品方向决策：产品主线押"更好用"还是"更便宜"，二选一。
- 结尾必须给一个明确建议加理由，能被决策会直接采纳或否掉。
- 建议要说清换取它放弃了什么、以及什么证据会推翻它；不要"两条腿走路"或"再看数据"。

## Context

- 营销自动化 SaaS，年营收约 200 万美元；该数字只作规模背景，不作为论据或推算基数。
- 客户是 50 人以下公司，反复抱怨产品太复杂、太贵。
- 去年调价反响不好，价格动作带负面记忆；评估"更便宜"方向时必须把这笔旧账算进去。
- 竞品与自身同在中小企业营销自动化区间、体量相近；企业级厂商的玩法不适用。

## Materials

- 一手源：三家竞品官网（产品页、定价页、功能说明）；厂商由执行方按同区间选取，outline 首行列出待我确认。
- 一手源：我整理的用户评论；只用于痛点、抱怨频次和原话，不用于市场规模类结论。
- 禁用：二手评论汇总文章、评测榜单、SEO 内容农场；其结论、评分和数字一律不引用。
- 冲突时排序：官网 > 用户评论 > 其他；官网只取事实（功能、定价结构、限额），评论只取痛点与语气。
- 任何数字（价格、席位、限额、评论条数）查不到就留空并标"未找到"，不估算、不用行业均值代替。

## Boundaries

- 不编造 ARR、用户数、增长率、转化率、留存、NPS；无来源就写"未知"。
- 不动付费等级架构（档位数量、每档包含什么、如何打包）；定价的说法与定位可以讨论。
- 不给"两者都要""视情况而定"这类结论；每条判断都要带取舍，禁止只有形容词的优劣对比。
- 不把去年调价简单归因为执行失误或单纯定价过高，除非素材里有对应证据。
- 只在 docs/briefs/ 下产出文件，不改动工作区其他内容。

## Done

- outline 每节标注将用哪份素材支撑，证据不足的节直接标"证据不足/未找到"，不留空话占位。
- outline 同时给出全文形态（几节、每节大致长度），我确认后才展开全文。
- 停止点：outline 未确认就不往下写；全文改版也先等我反馈。

## Assumptions

- 三家竞品未点名：按"客户 50 人以下、营销自动化、易用性与价格是主要卖点"选三家同类厂商，在 outline 首行列出，你可当场替换。
- "我整理的用户评论"目前不在工作区：视为你在 outline 评审时提供或给出路径；在此之前评论类证据留白，不拿二手文章补位。
- 决策标准按你给的两条（更好用 / 更便宜）；若还有第三条（渠道、集成、服务等），请在审 outline 时补。
- 读者是你和参与方向决策的人，outline 按"开会能直接过一遍"的密度写。
