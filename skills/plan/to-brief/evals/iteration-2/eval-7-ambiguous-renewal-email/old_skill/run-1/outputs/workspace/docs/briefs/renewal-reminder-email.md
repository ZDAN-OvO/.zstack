# Brief: 一封让老客户在到期前完成续费的中文邮件

- Stage: execute
- Source: 用户原话「帮我写一封续费提醒邮件，目标是让老客户续费。价格参考 price.md，别承诺折扣。语气要高级一点。」

## Goal

- 客户方读完后的决定只有一个：是否按当前套餐再续一年（本期邮件不承担涨价、升级、加购的目标）。
- 邮件必须让收件人不用回问三件事：续什么、多少钱、什么时候到期。
- 成功标准是续费动作发生，不是邮件写得漂亮；因此每段都要指向"下一步怎么做"。

## Context

- 收件人是客户的采购/决策人（能签年度合同的人），发件人是客户经理或客户成功，一对一邮件，中文。
- 产品名、发件人姓名与职位、客户当前套餐、合同到期日：请求里都没有，邮件内一律用 [方括号] 占位，不得虚构。
- 客户是已付费满一年的老客户，有使用历史，续费对象是同一套餐再续一年。
- `price.md` 只有三档年费，没有客户与套餐的对应关系：Basic ¥3,600/3 席位，Team ¥12,000/10 席位，Business ¥36,000/30 席位。
- 邮件是到期提醒，不是账单通知：重点在时间点与确认方式，不解释产品价值的长篇论证。

## Materials

- 唯一价格来源：`price.md`（2026 价格表）；只允许引用客户当前套餐那一档，金额与席位数照抄，不改写成月费、不四舍五入。
- 除 `price.md` 外不引入任何数字：用量、节省金额、ROI、同行案例、客户名单一律不写。
- 需要但缺失的信息（客户名、套餐、到期日、发件人、联系方式）留 [占位符]，并在文末列出占位符清单；缺什么写什么，不猜。
- 不套用未提供的品牌语调文档或历史邮件；语气标准见 Boundaries。

## Boundaries

- 不承诺、不暗示、不讨论任何折扣、返点、赠期、免费席位、分期；也不写"可以再谈"。
- 不用促销与施压手法：无感叹号、emoji、"限时""仅剩""最后机会""错过将涨价"，不制造焦虑，不暗示价格即将上调。
- 不虚构价格、席位、客户名、案例、用量、发件人身份或联系方式；缺的一律占位。
- "高级"的落地标准：短句、克制、少形容词，不写"尊贵的客户"这类套话，不堆敬语，专业而不热络。
- 不评价竞品，不承诺服务范围之外的东西（SLA、专属支持等未提供即不写）。

## Done

- 产出 `docs/drafts/renewal-reminder-email.md`：主题行（1 条主选 + 2 条备选）、正文（中文，≤200 字）、署名区、文末占位符清单。
- 只出这一版给我审：不写跟进邮件、不做多语言版本、不做 A/B 变体。
- 正文每个数字要么能在 `price.md` 找到，要么是 [占位符]；我逐条核对后再决定改不改。

## Assumptions

- 交付形态暂按"可复用模板"处理（含占位符），因为"老客户"是群体；若要发给某一个具体客户，给我客户与套餐即可改成单封。见 Open questions Q1。
- 本期不谈升级或加购；如要顺带推高套餐，需在 Goal 里另立一条。
- 价格若与客户去年支付的不一致，邮件不解释原因、不道歉、不承诺补差——这一条按"别承诺折扣"的同类风险默认关闭。
- 缺失的发件人身份用 [客户经理姓名]/[职位]/[联系方式] 占位，不编造真实人名。

## Open questions

- Q1 交付形态：可复用模板（占位符 + 占位符清单），还是发给某一个具体客户的单封邮件？
- Q2 金额口径：正文是否写出年费数字？我倾向不写金额、只写"按您当前套餐的年费续费"并把明细留给报价单/附件，因为 `price.md` 没有客户与套餐的对应关系。
