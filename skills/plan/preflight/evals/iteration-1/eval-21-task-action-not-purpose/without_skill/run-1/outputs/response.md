**请补充 3 个信息：**

1. **你的产品/赛道是什么？** 例如「面向中小团队的 SaaS 客服工单系统」「跨境独立站建站工具」。
2. **分析哪 5 家？** 你指定，或我按赛道帮你挑市占率最高的 5 家（那你得先回答第 1 题）。
3. **决策用途？** 这决定分析的重点：
   - 定价页改版 → 重点拆价格锚点、套餐分档、免费额度
   - 新功能立项/路线图 → 重点拆功能矩阵、缺失项
   - 融资/BP → 重点拆市场格局、差异化空间
   - 销售打法 → 重点拆优缺点话术、替换成本

**说清后我会交付：**

| 交付物 | 内容 |
|---|---|
| 功能矩阵表 | 5 家 × 功能维度，✓/✗/部分，标出你的差异化空隙 |
| 定价对比表 | 套餐分档、单价、免费层、隐藏成本（按座位/流量/API 计费） |
| 优劣势 | 每家 3 条优势 + 3 条短板，附证据来源 |
| 结论 | 价格带空白、功能空白、可切入的定位 |
