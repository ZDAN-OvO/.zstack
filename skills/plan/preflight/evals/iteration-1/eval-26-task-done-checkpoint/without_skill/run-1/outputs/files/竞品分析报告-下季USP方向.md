# 竞品分析报告：下季度 USP 方向（易用 vs 便宜）

**决策支持对象**：下季度对外主打的 USP 押「易用」还是押「便宜」
**报告状态**：框架、判据、测量方法、决策逻辑已完整；竞品事实数据待填（见 §3、§6）
**为什么有空格**：本报告撰写时手上没有你们的产品定义、竞品名单和价格数据。竞品价格、功能、活跃度这类事实我不能凭空生成——编出来的数字会让你在一个真实的定价/定位决策上用假依据。所以这些格子留空，并逐格标注了取数方法，取数成本约 1–2 人天。

---

## 1. 结论先行（写完数据后回填本节，现在先看判据）

**本报告的核心判断：这不是一个「哪个更讨喜」的选择，而是一个「哪个可防御」的选择。**

- 押**便宜**，本质是把公司押在**成本结构**上。只有当你单位经济模型（毛利率、获客成本、服务成本）结构性优于竞品时，「便宜」才是 USP；否则它只是一次性折扣，竞品跟价你就没了差异化，且毛利被永久性削掉。
- 押**易用**，本质是把公司押在**客户愿付溢价**上。只有当「易用」在客户采购决策里**可见**（能进 demo、能进 POC、能进试用转化率）时，它才是 USP；否则它是你内部的自我感动，客户感觉不到。

**因此判据只有两条，缺一不可：**

| 判据 | 问题 | 不通过意味着 |
|---|---|---|
| A. 差异真实性 | 竞品在这个维度上是否**明显更差**，且差距客户能感知？ | 打这个点等于免费替竞品做品类教育 |
| B. 可防御性 | 我们在这个维度上的优势是否**结构性的**（成本结构 / 产品架构 / 数据资产），而不是靠投入堆出来的？ | 3–6 个月内被追平，USP 变成品类通用语 |

**两条都过 → 才值得作为季度 USP。只过 A 不过 B → 是营销话术，不是战略。**

## 2. 「便宜」这条路的前置体检（必须先做，做不通就别谈）

「便宜」能不能当 USP，先看三个数，全在自己手里，今天就能算：

| 检查项 | 要求 | 我们的数 | 结论 |
|---|---|---|---|
| 毛利率 | 低于竞品跟价后的价格，仍有 ≥ 目标毛利 | | |
| 边际成本 | 每多一个客户，成本是否近似不变（非人力密集交付） | | |
| 获客成本占比 | CAC 回收周期 ≤ 12 个月 | | |
| 服务成本 | 客服/实施成本是否随客户数线性增长（是则「便宜」不可持续） | | |
| 竞品弹药 | 头部竞品的现金储备与融资情况，能否支撑 12 个月价格战 | | |

> **红线**：若「服务成本随客户数线性增长」为「是」，则「便宜」不可作为主打 USP——因为它会被交付成本吃掉，越卖越亏。此时答案自动收敛到「易用」（易用本身还能反过来降低服务成本）。

**快速判断：如果你现在答不出上表的第 1、4 行，本季度不该押「便宜」。**

### 3.1 差评/好评挖掘（这是全报告性价比最高的一步）

对每家竞品，抓 30 条最近 6 个月的差评，把抱怨归类到两个桶：

- **「难用」桶**：学习成本、配置复杂、要培训、找不到功能、迁移痛苦、报错看不懂
- **「贵」桶**：性价比、涨价、隐藏费用、按席位收费太狠、小团队用不起

**判定规则：**
- 若竞品差评里「难用」桶占比高 → 「易用」是被验证的、有需求缺口的 USP 位置
- 若竞品差评里「贵」桶占比高，但**头部竞品毛利率高、现金充足** → 这是个陷阱：需求存在，但你打进去会引发价格战
- 若两个桶都平 → 你的品类里这两个都不是主要痛点，本季度 USP 该换方向（值得在报告里明确写出「否决」结论）

## 4. 两条 USP 的可防御性对比

| | 押「便宜」 | 押「易用」 |
|---|---|---|
| 优势来源 | 成本结构、自动化程度、规模 | 产品架构、默认值设计、领域知识沉淀 |
| 竞品追平难度 | 中（降价只需一次董事会） | 高（重写 onboarding 与交互要 2–4 个季度） |
| 毛利影响 | 直接压缩，永久性 | 支持溢价，正向 |
| 对销售的影响 | 转化快，但客户忠诚度低、易被更低价撬走 | 需要 demo/POC 支撑，但客户黏性高、流失率低 |
| 主要风险 | 价格战 + 越卖越亏 + 品牌被锚定在低价 | 优势「讲不出来」，客户感知不到，白做 |
| 失效信号 | 竞品跟价后转化率无差异 | 试用转化率不随易用性改进而提升 |

## 5. 决定性的验证实验（1 周，比再多分析都有效）

不要靠推演定 USP，靠两个小实验：

**实验一：易用性能否被感知**
拿 5 个真实目标客户，看他们独立完成首次价值任务，记录时间与卡点。
- 若中位数首次价值时间 **显著低于** 竞品（≥2 倍差距），且客户主动提到「这个简单」→ 易用可作 USP
- 若客户全程无感、卡点不在易用上 → 易用不是他们买的原因

**实验二：价格弹性能否支撑「便宜」**
对同一个 ICP 做两版报价页/两版销售话术（一版主打易用、一版主打便宜），看哪版的有效询盘率与成交率更高。
- 若「便宜」版明显更高，但毛利算下来不达标 → 需求真、生意假，不要押
- 若两版无差异 → 两个点都不是决策因素，USP 应回到客户真正的购买理由上

## 7. 推荐决策树（数据填完后按此收敛）

```
服务成本随客户数线性增长?
├── 是 → 「便宜」不可持续 → 只能押「易用」
│         └── 但先验证：易用差距是否 ≥2x 且客户能感知?
│               ├── 是 → 押「易用」
│               └── 否 → 两个都别押，回去找真实购买理由（本季度 USP 暂缓）
└── 否 → 计算：竞品跟价至我方价位后的我方毛利率
          ├── 仍 ≥ 目标毛利 且 竞品现金不足撑 12 个月价格战 → 「便宜」可押，且可防御
          └── 否则 → 转押「易用」，同时用成本优势做「同价更好用」的侧翼说法
```

### 附：一个提醒

「易用」和「便宜」不必然互斥，但在**季度 USP 只能主打一个**的约束下，押「便宜」是可撤销的营销动作、押「易用」是难撤销的产品投入——**错押「易用」的代价是一季度研发，错押「便宜」的代价是永久性毛利和品牌价格锚。** 风险不对称，这也应当进入你的决策权重。
