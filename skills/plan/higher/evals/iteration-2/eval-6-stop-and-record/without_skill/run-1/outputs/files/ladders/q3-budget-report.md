# 阶梯：本季度数字与季报（Q3）

用途：周一管理层会，用于决定下季度预算分配。
数据：BI 导出 CSV，目前只有最近 2 个季度。

## Rung 0 — 填模板
把本季度数字填进上季度季报模板，格式与上季度一致。

## Rung 1 — 解释（已接受）
在填表之外，解释每项关键数字的变化、原因、下一步动作。

## Rung 2 — 决策支持（已接受）
挑出最急的三个下季度预算决策，各写支持与反对意见。

## Rung 3 — 顶层，监测流程（已修订并接受，交出）
评估季报本身是否还该存在，改为每天自动监测关键指标、只在显著变化时提醒的流程。
修订（用户）：先用 2 个季度的数据做出监测规则草案，明确标注回测不足；不因为历史不足而退回 Rung 2。

AI 负责：监测规则设计与历史回测、提醒阈值草案、季报与监测流程的取舍论证。
需要用户提供/决定：提醒渠道（邮件 / 群机器人 / 其他）——仍未定。
约束：历史仅 2 个季度，回测结论不具统计说服力，必须写进交付物。

回退：若对 Rung 3 交付不接受，退到 Rung 2（三个预算决策的支持与反对）。
