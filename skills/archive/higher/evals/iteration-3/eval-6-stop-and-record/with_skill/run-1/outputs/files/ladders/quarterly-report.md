# Ladder: 季度数字填模板 → 到自动监测季报

用途：周一管理层会，决定下季度预算分配。数据：BI 导出 CSV（现有 2 个季度）。

| Rung | Goal | AI owns | Needs | Status |
|---|---|---|---|---|
| 0 | 把这季度的数字填进上季度的季报模板 | | | accepted |
| 1 | 在填好的模板上解释变化、原因和下一步 | 从 CSV 对比两季度、归因、写行动建议 | 两季度 CSV、模板口径 | accepted |
| 2 | 挑出最急的三个预算决策，各写支持与反对 | 排序、为每个决策组织正反两面论据 | Rung 1 的产出、决策标准 | accepted |
| 3 | 先用两个季度的数据做出监测规则草案，标明回测不足（评估季报是否还该存在，设计每天自动监测、只在显著变化时提醒） | 监测规则草案、阈值与触发条件、回测说明 | 2 个季度历史 CSV、提醒渠道；回测只有 2 季度，偏弱 | handed |
