# Ladder: 季度经营报告

用途：周一管理层会，决定下季度预算怎么分。数据来自公司 BI 导出 CSV（AI 无直连查询权限）。

| Rung | Goal | AI owns | Needs | Status |
|---|---|---|---|---|
| 0 | 把这季度的数字填进上季度的季报模板里 | | | |
| 1 | 解释这季度变了什么、为什么、下季度怎么做（用户："就按你写的"） | 归因分析：对比两季 CSV，找出变化项、给出原因假设、写出下季度动作 | 本季 + 上季导出 CSV；两季指标口径一致（同一定义、同一时间范围），否则对比无意义 | |

Handed over: 待定（ladder 仍在搭建，用户尚未叫停）
