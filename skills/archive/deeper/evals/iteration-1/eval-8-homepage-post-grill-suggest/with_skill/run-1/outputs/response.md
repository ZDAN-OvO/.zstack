先给一句方法上的实话：现在这个"转化率低"还不是一个能诊断的问题——没有基线、没有转化定义、没有对照。所以第 1 条不是文案建议，是前提检查。

**1. 前提：问题可能不在首页文案**【不确定，但这是先查项】
- 上个月换了广告投放渠道【已知】：新渠道的意图、关键词、地域、设备都可能和老渠道不同，"转化率变低"很可能只是流量结构变了。先按来源/媒介拆分看各自转化率，而不是看总盘子。
- 其他同样常见的成因：GA4 事件或归因窗口改过，指标本身不可比；广告实际直达的是某个落地页，不是首页；转化发生在 demo 预约或销售环节，而不是注册；移动端占比高但首屏在手机上根本读不完；季节性。
- 如果拆分后是"各渠道内部转化率没变、只是低质渠道占比变大"，改文案基本白改——该动的是投放或分渠道落地页。那已经超出"改首页文案"，可以交回 `/higher` 重新定义这一步。

**2. 原始材料：你手上已经有，别先看汇总报表**
- Hotjar 录屏 + 热图（3 个月）【你有】：只看"从广告进来的会话"，看首屏滚到哪、CTA 有没有 rage click / dead click、表单在第几个字段放弃。看 20–30 段，别只看热图平均色。
- Intercom 对话【你有】：把近 3 个月进线做编码——客户用自己的话怎么描述问题、哪句话让他们决定预约或关掉页面。方法叫 voice-of-customer 编码（按"触发场景 / 现在的做法 / 障碍 / 期望结果"归类），适用场景正是没有用户研究预算、只有客服记录。
- GA4【你有】：按来源分组的 30 天对比前 30 天；首页 → 下一步的路径和主要退出页。
- 你没有、但值得补的【不确定拿不拿得到】：广告后台的搜索词/受众报告、销售侧"线索不合格"的理由、表单字段放弃率。

**3. 方法（都带适用条件）**
- 信息匹配（message match / scent of information）：只在确认渠道结构变了之后用——核对广告承诺和首屏第一句是不是同一件事。
- 5 秒测试：改版前用它筛 3–5 版首屏，5 个人、半小时，能便宜地淘汰"自己觉得好但别人读不懂"的版本。适合你没有 A/B 工具、又要两周内定稿的情况。
- 分渠道前后对照（准实验）：没 A/B 工具时的替代——改版前后各取两周，同时留一个未改动的渠道/落地页做对照。前提是那条渠道量够、且改动不同期上线。它只能排除大错误，证明不了小幅提升。
- 首屏结构改成"问题 - 方案 - 证据 - 下一步"：只在访客已经知道这类产品存在、而当前首屏在讲功能而不是结果时才用。

**4. 证明：没有 A/B 工具怎么算数**
- 第一步先把"转化"钉死（哪个事件、什么归因窗口、算不算销售合格）【必须先做，否则后面所有数字都不可比】。
- 代理指标按出现顺序看：首屏 5 秒内是否滚动/停留 → CTA 点击率 → 表单开始率 → 完成率 → demo 预约率。前两个 3–5 天就有方向，最后一个两周内大概只有个位数样本【不确定，取决于你的真实转化量】。
- 诚实说：月访客 8000，若转化率 1–3%，就是每月 80–240 次转化；两周的样本量下，就算有 A/B 工具也很难得到显著结果，前后对比更拿不到因果结论【不确定具体功效，但方向上是这样】。所以两周内能给的是"排除了哪些原因 + 方向性证据"，不是"文案提升了 X%"。要真结论，得建持续测量（按周轮换或留 holdout），那是 2–3 个月的事。
- 补充证据：改版后 Intercom 里新冒出来的困惑、销售说线索质量变化。定性，但很硬。

**5. 拉伸目标（可选）**
不是"把首页转化率提上去"，而是："两周内能说出每个广告渠道的访客在首页缺什么，让来源—首屏—CTA 三者一致，并留下一条能持续跑的分渠道基线。"差距报告：两周内前两条能做完，基线能建起来，但结论要等一个季度——如果只交"改完文案、转化率涨了"，这个目标就是没达成。
