- **材料是空的**：工作区里没有你们的赢单、丢单表、流失原因、工单标签，也没有竞品定价页存档。这些是唯一能验证结论的材料。竞品官网和「十大 SaaS」聚合文只能罗列功能，不能说明买家为什么又选了别人。拿不到自有数据，建议退成一页决策简报，而不是完整报告。
