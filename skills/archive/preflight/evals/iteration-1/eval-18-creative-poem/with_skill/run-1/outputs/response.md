先不退让地写。一件事先说：**通用诗是废品**——"慈母手中线"式的比喻，任何妈妈的女儿都能发，那不是给你妈写的。

要用一分钟对一下意图吗？我需要你回答四个问题（只有你知道，文件里查不到）：

**1. 用途** — 这首诗最后出现在哪？生日当天私信她 / 发朋友圈 / 写在蛋糕贺卡上 / 家族群里念出来？这决定长短和口吻。

**2. 具体** — 挑两三样**只有你妈对得上**的东西：她几岁、你怎么称呼她、她最近在忙什么（种的花、跳的广场舞、做的某道菜、手机里存的什么）、你们之间最近一件真事。

**3. 墙** — 有什么绝对不能写的？（病、钱、离世的亲人、她不爱听的话、太肉麻她会嫌）

**4. 形状** — 四句？八行？要不要念得出口（那就得有韵、句子短）？要不要夹一句方言土话？

顺带我提三个升高的选项，你接受、改或否掉都行：

- **升一级**：不只给诗，给"生日那天你要对她说的那段话"——诗＋一句你自己的大白话＋怎么送出去。
- **下一层**：红队审稿。写完之后我换一个"挑刺"的视角，逐句问"这句是你妈本人会点头的，还是任何妈妈都能用的"，把后者删掉。删完剩下的才交给你。
- **降一级（备选）**：如果你觉得对不上，我就先写三行粗糙的、只图有个开头，你在上面改。
