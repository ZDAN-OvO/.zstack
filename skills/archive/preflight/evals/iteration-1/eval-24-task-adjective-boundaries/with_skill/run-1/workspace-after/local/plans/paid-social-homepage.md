# Plan: 付费社媒访客的首页首屏

- Asked: "帮我重做首页视觉" — 目标是付费社媒来的新访客 5 秒内看懂我们是干嘛的；边界是"高级、简洁、有科技感"
- Stage: execute
- Date: 2026-11-10

## Requirement

**Hand over**: 付费社媒访客在首屏知道「这是什么品类 / 给谁用 / 和 Notion 差在哪 / 多少钱」→ paid_social 转化率从 1.9% 回到 organic 的 4% 区间。
**Fallback**: 只改首屏（hero + 首屏 CTA），做 A/B，两周后用 paid_social 队列判定。

**Depth**: 你问的是视觉，但数据先说话。10-20 起 paid_social 流量翻倍（11.8k→21k），转化同时腰斩（3.9%→1.9%）——这是信息不匹配，不是审美问题。chat 里的三条真实反对意见是：跟 Notion 没区别、找不到价格页、注册要连日历就放弃。所以专家动作是：首屏先回答这三个反对意见，再谈高级感。
原始材料：support/chats-sample.md 的原文措辞；analytics/weekly.csv 的分渠道队列。
工具：按 top_source 拆分的周转化、5 秒测试（目标用户看首屏 5 秒后复述）、CTA 点击埋点。
**Stretch**: 找 5 个付费社媒画像的陌生人做 5 秒测试，≥4 人能一句话说出品类 + 和 Notion 的区别。

**Range**: "首页视觉"是个名词，它要产生的效果是三个动词 —— 读懂（品类与差异化）、信任（专业度）、行动（点 CTA）。
crew：定位/信息层级（决定首屏只留几句话）· 转化文案（一句话说清品类、对象、差异）· 视觉设计（把高级/简洁/科技感落成具体版式与字体）· 前端首屏性能（科技感常和首屏加载打架）· 增长实验（A/B + paid_social 队列口径）。
red team：一个 Notion 老用户 + 一个从付费广告点进来的陌生人，任务是"给我一个关掉这个页面的理由"。

**Judge**: 短期你自己看 3 个文案方向 + 2 个缩略 moodboard（便宜、能直接否定）；上线后 paid_social 两周转化 vs 1.9% 基线。审美由你判，"5 秒看懂"不能由我们互判。

**Needs**: 缺产品品类/目标用户/价格/与 Notion 的差异点（不是我该猜的）· 缺"高级科技感"的参考站点 2–3 个 · 缺现有页面埋点与 A/B 权限。

## Task

**Purpose**: 付费社媒的投放要不要继续加预算 —— 首页得让这批人看懂并转化。
**Context**（我查到的，请确认）：现首页是占位文案，通篇"all-in-one platform / seamless / AI-powered"，无品类、无对象、无价格、无差异化。10-06→10-27 期间 paid_social 从 0 变主要来源，转化由 3.9% 掉到 1.9%。support 样本三条都在抱怨理解成本和注册摩擦。
**Materials**: 一手 —— index.html、analytics/weekly.csv、support/chats-sample.md。二手/禁用 —— 暂未指定（建议禁用竞品营销话术，那是空话的来源）。
**Boundaries**: 你给的是方向词（高级/简洁/科技感），不是墙。需要你点头的候选墙：
1. 不许出现"all-in-one / seamless / AI-powered"这类无品类空话
2. 首屏只留一个 CTA，不做多按钮并列
3. 本次不动注册流程（日历授权那一步另开）
4. 不加价格页，只在首屏点明价格区间
**Done**: checkpoint —— 先给你 3 条 hero 文案（品类 + 对象 + 差异化）＋ 2 个灰度 moodboard，你选定后才做整页。交付 —— 可上线的移动端首屏页 + 5 秒测试记录 + 埋点方案。看到这三样就停。
