## 一个前提问题：这些价格没法直接横比

六家里有五家改成**积分/Credits 计费**，标价只卖"额度"，不卖"次数"。同一个 ¥99/月，CodeBuddy 给 4000 积分、Trae 给 4000 积分、Comate 给 25000 积分——单位根本不同。所以比价必须落到"团队一个月实际消耗多少积分"，否则标价表会误导采购。

## 对"下季买哪家"的建议

- **如果团队只是要"便宜的强模型 + 保留自选工具"**：GLM Coding Plan。¥94.4/席/月的连续包月价是全表最低的单位成本，而且能接 Claude Code / Cursor / CodeBuddy 等 20+ 工具，不锁 IDE。风险是 5 小时+每周双限额，重度用户会撞墙。
- **如果有 10 人以上、要 SSO/审计/成本管控**：Qoder CN 企业标准版 ¥149/席/月，是唯一把"企业管控能力"写进公开价目的；要 VPC/独立实例就上 ¥199 档，但**50 席起售**，小团队进不去。
- **如果要私有化部署（数据不出内网）**：只有 Comate 和 Trae 明确提供，两家都必须商务谈判，没有公开价——意味着这是采购流程问题，不是比价问题。
- **不建议**单纯按个人档最低价买：Comate 企业版 ¥138/双席位看着最便宜，但**模型资源单独计价**，实际总价可能翻倍；Trae/CodeBuddy 的"首月价""限时特惠"是促销价，续费回到原价。

## 要给你算出确定金额，我还缺两件事

1. **团队多少人、其中重度使用（每天几小时）的有几个**——决定买 Lite 档还是 Pro 档、要不要混买。
2. **是否必须私有化/VPC**——这一条直接砍掉一半候选，也决定谈判还是下单。

给我这两个数，我按 3 个月的实际用量把各家总价算出来，连"积分够不够用"的估算一起给你。
