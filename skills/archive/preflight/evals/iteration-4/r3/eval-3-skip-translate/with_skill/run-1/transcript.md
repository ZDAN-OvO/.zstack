ASSISTANT: **Translation:** This week's launch has been pushed back to Friday.

Variants by register:
- **Release notes / status update:** This week's release is postponed to Friday.
- **Ops / go-live:** The go-live planned for this week has been delayed until Friday.
- **Casual standup:** We're pushing this week's launch to Friday.

Two ambiguities worth confirming if it goes to an English-speaking audience: “上线” (launch / release / go-live / rollout) and whether Friday is the new go-live date or the new decision date ("延期到周五" most naturally reads as the new date).
