- Asked: "帮我重做首页视觉"
- Stage: execute

## Requirement
Hand over: 第一屏（首屏）重做 —— 付费社媒访客在 5 秒内能说出「这是什么类别 / 给谁用 / 用了会怎样 / 下一步点哪」；产出文案+视觉+可渲染的首屏，按 5 秒测试评分卡验收。
Fallback: 只做视觉层（文案冻结）：字体、留白、单一签名元素、首屏层次，不动任何措辞。
Depth: 原始材料 = 实际投放素材与落地 URL（缺）、support 聊天样本（有 3 条反对意见）、weekly.csv；仪器 = 5 秒回忆测试协议 + 「广告→首屏」信息匹配矩阵 + 转化 A/B（2%→4% 需 ~1.1k/周/组；+20% 相对需 ~21k/组 ≈ 2 周全站流量）；stretch = 反证「是视觉的问题」：先做纯文案修复（零视觉改动）与现页同测，若纯文案已补齐理解缺口，则视觉重做降级为可选。
Range: 动词 = 让陌生人一句话说出类别 / 让他看见自己会经历的某个动作 / 让他相信（证据而非形容词）/ 让他知道下一步 / 不让他转身去找 Notion。班底 = 定位与信息架构（类别+人群+单一承诺）、转化文案（6 字主张多版）、品牌视觉（字体/空间/一个签名元素）、前端（移动端 LCP，广告点击多为 4G 手机）、红队（刚在手机上点开广告、只有 5 秒的怀疑型滑动者）、分析（判定样本是否支持结论）。
Judge: 5 秒测试 —— 8~12 名非内部、盲测被试，只问「这家是做什么的/给谁/会不会点」，评分卡判「类别命中 + 下一步可指认」；模型自跑兜底 = 全新会话冷读（只给渲染图，不解释）做三份互盲，再由分析位裁定是否成立。判方法也判结果：改对了但靠猜（说不出为什么这版能过）记不及格。
Needs: 需投放素材/落地页 URL（缺）、品牌资产与产品截图/设计规范（缺，仓库只有 2 行文案的 index.html）、可受访被试（缺）、埋点（滚动深度/停留、当前无）、首屏性能预算下的移动端真机。

## Task
Purpose: 你说的是「让付费社媒新访客 5 秒内看懂我们是干嘛的」—— 这是度量，不是决策。要问清：这个结果要喂给哪个决定（继续加投付费社媒 / 改落地页 / 改广告），否则做完了没人拿它做决定。
Context: 已查证事实，待你确认：① 第 3~4 周 paid_social 已成第一来源（19.5k→21k 访问），但转化 2.0%/1.9%，organic 为 3.9%；整体转化从 4.0% 掉到 1.9% 是**结构漂移**（两组各自都没变差），不是页面变差。② support 三条反对意见：「和 Notion 有什么区别」（定位）/「价格页在哪」（导航/信息架构）/「注册后要连日历就放弃了」（注册后流程，首页改不到）。③ 现页只有 H1「The all-in-one platform for modern teams」+ 一句「AI-powered workspace」+ 一个 CTA —— 没有类别名、没有对象、没有证据、没有导航。仓库里**看不出产品到底是做什么的**。
Materials: 一级（按序）= 投放素材与落地 URL【缺】> support 聊天样本【有】> weekly.csv【有】> 现页 index.html【有】> 外部一级源：买家自己的用词（支持工单、评测、品类页），竞品首屏只作「品类惯例」参照不作文案抄袭源。禁用源：待你定。空位：品牌/设计规范、产品截图、现有视觉稿。【缺】
Boundaries: 你给的是「高级、简洁、有科技感」—— 这是方向和形容词，不是墙；它们无法否掉任何一版产出。真正要问的是 don'ts，尤其第一个：**文案能不能改？**（Purpose 是「看懂」，而看不懂的根因在文案不在视觉：现页没写品类、没写对象）。其余候选墙：CTA/注册路由冻结、导航与法务区不动、不引入我们证不了的宣称、不用图库人像、不改产品名。
Done: 停手时眼前应有 ① 3 版 6~12 字主张 + 各自理由；② 移动端与桌面端可渲染首屏（仓库内 HTML/CSS）；③ 5 秒测试脚本 + 评分卡。早期检查点 = 主张 3 版 + 线框，**先给你过，再动样式**。
