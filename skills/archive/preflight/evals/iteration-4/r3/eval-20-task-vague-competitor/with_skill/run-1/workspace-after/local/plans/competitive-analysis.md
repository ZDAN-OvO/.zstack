## Requirement

（三轴皆为建议，请逐条 接受 / 改写 / 拒绝）

- **Hand over**: 第 3 级 —— 讲清竞品各自在取舍什么，并落到下季度一个方向建议，附正反论证。第 4 级（持续追踪竞品价格/功能/融资/评价，并自动驱动定价决策）今天超出模型能独立承担的范围，是本次的天花板。
- **Fallback**: 第 2 级 —— 只讲差异与取舍，不给建议（当你还没准备好在会上被要求拍板时用）。
- **Depth**: 起点不是竞品官网的营销文案，而是它们无意中留下的痕迹：定价页历史快照、changelog / release notes、招聘 JD、客户差评原文、财报与融资披露。工具决定方法：抓取加存档、价格历史比对、评价语料统计。拉伸目标 —— 从评价语料里找出一个"所有竞品都没满足"的需求，并给出可被后续数据推翻的预测。
- **Range**: 这份东西要干的动词是「让人在半小时内相信一条因果关系、并在不确定下做一次取舍」，不是「罗列五家」。所以要的班底：行业分析师（拆商业模式与单位经济）、调查记者（挖未公开的动机、人事、融资）、定价策略师、一线销售（真实的赢单输单异议）。红队：做空机构 + 前竞品员工，任务只有一个 —— 证明"我们的差异点其实不成立"。
- **Judge**: 每条结论必须挂一手来源（定价页快照 / changelog / JD / 评价原文），挂不上就删。另起独立 session 只做证伪，再由第三个 session 裁定哪条反驳成立；被驳回的反驳记下理由。你自己就在这个市场里，若你能直接判断好坏，以你的判断为准，但仍要求逐条有源。
