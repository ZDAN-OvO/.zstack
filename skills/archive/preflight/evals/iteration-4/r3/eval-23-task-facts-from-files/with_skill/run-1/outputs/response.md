**Altitude** — 交出去的不是填好的模板，而是"为什么 Q3 在退，以及下季动哪一根杠杆"的结论。爬一级：老板拿它去 VP 会上做决定（续不续投试用政策）。再往上一级（模型替公司定试用策略）超出我能承担的，所以**回退档 = 填好模板 + 一页因果解释**。

**Range** — 把"回顾"还原成动词：解释（分析）、证伪（红队）、建议（经营）。班子：财务（收入桥）、客户成功（流失与工单）、增长分析（试用漏斗）、红队（专攻"这不是因果，是季节"）。
**Judge** — 内部数据没有外部标准答案，所以：另起两个会话分别当红队攻击结论、再一个会话裁决双方，评判的是**方法**（是否排除了竞争假设）而不只是数字对不对。你若自己能判断，你的判断就够。
