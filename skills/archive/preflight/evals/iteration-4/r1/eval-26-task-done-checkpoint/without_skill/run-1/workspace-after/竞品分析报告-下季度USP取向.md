# 竞品分析报告：下季度 USP 取向（易用 vs 便宜）

**决策**：下季度对外主张押"易用"还是押"便宜"
**用途**：定 USP 主轴、定定价页文案、定季度营销预算分配
**状态**：框架与判据已完整；标 `【待填】` 的事实格需你补入（本报告未掌握我方产品/市场/竞品数据，未做任何虚构）

---

## 一、结论先行

**默认建议：押"易用"，但只在满足下方三条闸门时成立；任一不满足则改押"便宜"。**

| 闸门 | 判据 | 不满足时 |
|---|---|---|
| G1 价差可感知 | 我方与最直接竞品的入门价差 ≥ 30%，或客单价差 ≥ 1.5 倍 | 便宜讲不出差异，只剩"略便宜"=无效主张 |
| G2 低价可守 | 我方单位经济（毛利/单客户）能撑住对手跟降 20% 后仍为正 | 便宜是可被现金流碾压的伪护城河 |
| G3 易用可证 | 存在一个可量化、可被感知的易用事实（上手时长、配置项数、首价值时间） | 易用沦为形容词，无法进入决策 |

**三条全绿 → 押易用。G1 或 G2 任一红 → 押便宜（且必须绑定结构性成本优势，而非补贴）。G3 红而前两条绿 → 先补可证事实，不要上市主张。**

理由：易用是**可累积、可防御、可涨价**的资产；便宜是**可被复制、可被补贴战击穿、锁死涨价空间**的负债。但易用只有在①客户能感知价差、②我方成本撑得住、③能拿出硬指标时才优于便宜——否则"易用"是说给自己听的。

---

## 二、为什么这不是二选一（但必须选一个主轴）

对外只能有一个主轴，原因是对内资源与对外记忆点都是单通道：

- **双主轴 = 无主轴**：定价页同时喊"最简单"和"最便宜"，客户无法复述，销售无法开场。
- **主轴决定组织**：押易用 → 投产品/设计/引导/文档；押便宜 → 投供应链/自动化/获客效率。两套投资曲线不同，不能各投一半。
- **主轴决定客群**：易用吸引"时间贵、人少、要快"的团队；便宜吸引"预算硬约束、人力便宜、能忍受配置"的团队。这两个客群的成功指标不同。

**允许的组合**：主轴一个，副轴一个做**限定语**（如"最省事的 X，且比 Y 便宜一半"）。副轴不可独立成句。

## 五、价格与感知价差（G1 的证据来源）

- **真实价差** = 【待填】%
- **客户感知价差**：客户在无提示下能否说出"谁更便宜"？【待填：访谈 5 位客户的结论】
- **决策阈值**：多数 B 端采购在价差 <30% 时不以价格决策，而以风险/时间/迁移成本决策。

> **常见误判**：把"我方更便宜"当成"客户认为我方更便宜"。若竞品用"按结果计费/免费额度"重构了价格锚，账面价差会被客户折算掉。

## 六、可防御性对比

| | 易用 | 便宜 |
|---|---|---|
| 复制难度 | 中高（需产品+设计+持续打磨，见效慢） | 低（降价即可复制） |
| 被补贴战击穿 | 不会 | 会 |
| 对涨价的影响 | 支撑涨价 | 锁死涨价 |
| 边际成本 | 前期高、后期趋零 | 永久性毛利压制 |
| 见效速度 | 2–3 个季度 | 当季度 |
| 失败模式 | 自我感动式"简洁"，客户其实不在乎 | 赢来最不忠诚的客群 |
| 适合的公司状态 | 有产品差异化空间、现金流可撑 | 有结构性成本优势（非补贴） |

**结论性判断**：便宜若来自**结构性成本**（自研替代外采、自动化替代人力、直销替代渠道），是真护城河；若来自**补贴或让利**，是租来的增长，且会定义你的客群永久为价格敏感型，届时涨价即流失。

```
└── 否 → 继续
       价差 ≥30% 且 客户能感知？
       ├── 否 → 便宜讲不出 → 押易用（转 G3 校验）
       └── 是 → 毛利能否撑住对手跟降 20%？
               ├── 否 → 双输区：既不该打价格战，也还没握住易用
               │        → 本季度不下 USP 结论，先做成本结构或易用突破
               └── 是 → 结构性成本优势？

                       └── 否 → 押易用
G3 校验：能否拿出 ≥40% 领先的硬指标？
├── 是 → 主张可上市
└── 否 → 先补证据，主张延后一个季度（不要用形容词上市）
```

| 周 | 动作 | 产出 |

## 九、反向信号（出现即推翻结论）

1. 销售赢单/丢单记录里，"价格"出现频次 <"缺少功能"→ 便宜不是真痛点。
2. 客户上线后 30 天活跃度低 → 易用是假易用（买了不用 = 没解决）。
3. 竞品在我方押易用后 1 个季度内推出同类引导/模板 → 易用优势窗口 <6 个月，需叠加数据或生态壁垒。
4. 押便宜后获客成本下降但留存下降 → 在买低质量客群，需立刻重估 LTV/CAC。

## 十、必须补的 5 个事实（本报告的输入缺口）

1. 我方与 3 家直接竞品的**实际价格**（含最低档与典型档）。
2. 我方**单位经济**：单客户毛利、CAC、回本周期。
3. B 层是否存在**免费/捆绑**替代者。
4. 我方**首价值时间与配置项数**实测值（并对比竞品）。
5. 近 20 条赢单/丢单的**真实原因记录**。

> 这 5 项填齐后，第七节决策树会输出唯一答案；在此之前，任何"押易用/押便宜"的结论都只是偏好，不是分析。
