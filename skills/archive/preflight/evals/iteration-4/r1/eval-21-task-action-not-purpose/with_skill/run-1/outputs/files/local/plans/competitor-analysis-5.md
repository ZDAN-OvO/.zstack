# Plan: 5 家竞品的功能 / 定价 / 优缺点

- Asked: 帮我分析 5 家竞品的功能、定价和优缺点
- Stage: think（请求里没有市场、没有自家产品、没有要支撑的决策）
- Date: 2026-11-10

## Requirement

Hand over: 一份能直接支撑决策的竞争判断——「我们该在哪一格赢、该抄什么、不该抄什么、价格空间在哪」；功能/定价/优缺点只是其中的证据列，不是交付物的主体。（比放开手更上一级：直接给出定价与路线图建议。）
Fallback: 如果上面这级超出——退回「5 家 × 功能/定价/优缺点」的对比表，但每条结论带一手来源链接和抓取日期。
Depth:
- 原始材料：各家的定价页、文档、changelog、招股书/融资稿、招聘 JD、Wayback Machine 的价格历史、G2/Capterra 的一星与三星评论原文。
- 工具而非表格：按「买家要完成的任务」归一化功能（不比厂商的功能命名）；把标价换成单位价值价格（每席位 / 每用量 / 每次成功调用）；对评论做抱怨频次统计，优缺点从抱怨里长出来，不抄厂商话术。
- 专家动作（你没要求的那一下）：用「5 家」这个数量换成分段覆盖——在位者、低价颠覆者、上游平台玩家，各占一格；数量是结果，不是目标。
- Stretch target：给出一个能预测未见数据的判断（如「A 会在 12 个月内对 B 降价」），并用价格变更历史检验；押错即方法失败。
Range:
- 动词：对比（同一标尺）、判断（谁在哪个任务上赢）、预警（谁要动价 / 谁在补短板）、说服（给谁看都能复述）。
- Crew：竞品情报分析师（一手来源与时间线）、定价与打包策略师（单位经济学）、真实买家（采购时的取舍标准）、红队（分别论证每家会怎么打败你）。
Judge: 事实列逐条挂一手来源链接 + 抓取日期；结论列由独立攻击 session 尝试证伪你的排名，再由一个 session 裁定；方法分与结果分分开打（猜对但方法错的判失败）。
Needs: 市场与自家产品定义（缺）、5 家名单或筛选标准（缺）、定价页/文档的可访问性（未知，付费墙需备选）、Wayback 历史（免费）、评论平台账号（未知）。
Declined: —（等你裁决）
