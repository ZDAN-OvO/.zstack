## Requirement

Hand over（建议接这一级）: 不是"对比三个竞品"，而是"支持下季度一个取舍决定：我们的卖点该压哪一边——并给出一个可被证据推翻的主张 + 依据"。
Fallback（上一级若过界就退到这）: 按你指定的 3 家、你指定的维度，做一份带一手来源的结构化对比，不下结论。
Ceiling（今天超界的再上一级）: 持续监测——竞品一动价/一动功能就预警并给出应对方案。它要价格页历史快照、发布节奏抓取和"有权行动"三样，前两样能建，第三样不在模型手里。

Depth: 顶部分析师不会从对比表开始，而是从
  ① 最原始的材料：竞品定价页与产品文档的历史快照（Wayback 时点）、changelog/更新日志的时间序列、招聘 JD（暴露下一步要做什么）、你自己丢掉和赢下的单子的原始记录；
  ② 工具：价格包络（price envelope）拆解套餐边界、功能发布节奏曲线、功能矩阵，而不是 PPT 表格；
  ③ Stretch target：给出一个带验证日期的预测（例："A 会在 Q1 下调入门价"），或反证你现有的一个信念（例："客户走是因为贵"）——用原始评论/win-loss 数据去证伪。

Range: 这份东西真正要做的动词不是"对比"，是①让人相信某个差异点值得押注 ②让人在会里当场取舍 ③把噪音筛成信号。
  Crew（各做各的活，不是各说各的话）：分析师→建可比矩阵与发布节奏时间序列；调查记者→每个数字追到一手出处并主动找反面证据；定价策略师→算价格包络和套餐边界；红队（短空头）→只负责证明你的结论错。

Judge: ①逐条一手来源可查（数字来自二手测评文章=方法失败，即使结论碰巧对也判不合格）；②独立红队 session 攻击 + 一个裁决 session 定夺哪些反对成立；③若你自己就是这行的人、能一眼分辨好坏，你的判断即为准。

Needs: 你的产品与市场一句话定义｜竞品名单（含"为什么是这三家"）｜你手里的 win/loss 或客户反馈原始记录｜联网/存档访问（取定价页历史快照）。当前全部缺失：工作区为空，无任何产品资料。

Declined: 无（待你裁定）
