# Plan: 给妈妈的一首生日小诗

- Asked: 帮我给我妈写首生日小诗
- Stage: execute（但五个槽位还空着，实际停在 think）
- Date: 2026-11-10

## Requirement
Hand over: 不是"一首诗"，是**生日那天她真的被看见**——成品像素描，只能是你妈，装不到别人身上。
Fallback: 只交诗本身（≤16 行，三个版本），不延伸到卡片/录音/家宴安排。
Depth: 生手从"母爱伟大"起手，诗人从**一个具体细节**起手（她的一句口头禅、一道只有她做的菜、她抱怨过的一句话）。素材用你的一手记忆和她的原话，不用网上诗句。检验：把诗念给一个不认识你妈的人听，他应该能说出一个关于她的具体事实。
Range: 诗的作用是 让她愣一下 / 让她笑 / 让她留着 / 让她念给亲戚听。队伍：诗人（具体意象、口语节奏）、口述史采集（从你的记忆里挖真细节）、朗读/贺卡设计（断句和停顿，决定是念出来还是发微信）、红队（以你妈本人的口味挑刺：肉麻、看不懂、像悼词）。
Judge: 三道。①你自己出声念一遍，哪句念不出口就砍——这是真诚检测；②另一个会话当红队，只负责证明这首诗是 AI 写的、是套话、有编出来的细节；③最硬的一道：每个具体细节都要能追回你自己说的话，追不回的一律删。
Needs: 你的口述素材（全部缺失）；妈妈的性格与场合（缺失）；交付形式：念出来、手写、微信（缺失）。

## Task
Purpose: 待答 —— 这首诗要在生日当天起什么作用？（逗她笑 / 让她哭一次 / 走个形式发群里 / 让她收着）
Context: 待答 —— 你和她的关系、她多大、爱不爱肉麻、生日当天在哪、谁在场、你怎么称呼她、有没有方言。
Materials: 一手 = 你自己的记忆、她说过的话、家里的聊天记录和照片。二手 = 亲戚转述。禁用 = 网上的诗句、"白发/皱纹/岁月/港湾/康乃馨/烛光"这类套话、任何你没说过的细节。查不到 → 留空，不编。
Boundaries: 不提她的病、老、累、白头发；不写"你辛苦了"式说教；不出现上面那串套话意象；不超 16 行、念出来 30 秒内；不用生僻词和文言腔；不像 AI 写的。
Done: 先给你三个候选**细节**（各一句）让你挑，你点头之后才写整首。成品是三个版本：暖版、逗笑版、三行微信版，可直接念，附朗读断句提示。
