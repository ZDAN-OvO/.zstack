- Stage: execute
- Date: 2025-11-10

## Requirement
Hand over（待确认）: 一页决策备忘录 —— 按**我们的席位数与实际用量**算出每家下季真实花费，给出推荐 + 砍价杠杆 + walk-away 阈值
Fallback: 候选清单 + 定价口径定义 + 各家标价对照（不含成本模型），你看完再决定要不要往下走
Ceiling 尝试过: 替你走完采购流程（询价、谈折扣、签合同）—— 超出可代办范围，所以落在上一级
Depth: 原始材料 = 厂商**自己的定价页 + 官方文档里的配额/限流页**（list price 只是入口，真正决定账单的是配额与超额规则）；工具 = 一张按席位×调用强度的成本模型 + 敏感性表，不是一张对比表；stretch target = 用官网标价检验"国产比 Cursor 便宜"这个信念，并在我们席位下算出它什么时候不成立
Range: 动词 = 取证（价格可追溯）、建模（TCO）、砍价（预付/年付/席位爬坡）、卡合规（数据出境、私有化、开票）；crew = 采购（合同与折扣条款）、财务（TCO 与席位爬坡）、研发效能（采纳率→实际用量）、安全合规（数据边界）、红队（论证"这季先别买，用开源自建"）
Judge: 每个价格必须能回到厂商官网 URL + 抓取日期，无出处的数字直接判失败；另起一个红队会话论证相反建议，再由第三个会话裁决；评分看方法（成本模型可复现、敏感性可见），答对但无出处算失败
Needs: 团队席位数、当前在用的工具与合同到期时间、日均使用强度、是否要求私有化/数据不出境、预算上限 —— 全部缺失
