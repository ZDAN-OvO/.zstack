# Plan: 妈妈生日的一首短诗

- Asked: 帮我给我妈写首生日小诗
- Stage: execute
- Date: 2026-11-10

## Requirement
Hand over: 一首她能对上号的短诗 **＋** 交付方式（手写卡片 / 饭桌上念 / 微信发）——建议一起给，诗在哪出现决定了它长什么样
Fallback: 只写诗，交付方式你自己定
Depth: 原料＝你口述的一个真实场景（她做饭的背影、喊你名字的语气、只有你家有的习惯），不是形容词；工具＝口语短句、不押韵、只写动作；stretch＝把"妈妈"二字去掉，陌生人仍能认出这是**某一个人**的妈，否则重写
Range: 动词＝让她认出自己、让她笑一下、让她知道被看见；班子＝一个写口语诗的（删掉所有形容词，只留动作和声音）＋ 红队（专杀滥调：白发、皱纹、烛光、岁月、康乃馨、永远年轻）
Judge: 你自己念一遍，找那句"这不是我妈"；红队过一遍禁词表。你能当场判，所以你的判断就够
Needs: 一个只有你知道的细节——我没有，得问你要
