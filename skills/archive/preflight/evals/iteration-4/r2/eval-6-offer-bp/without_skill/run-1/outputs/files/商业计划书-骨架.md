# 【公司/项目名】商业计划书

> 用法：`【】` 是必须替换的内容。灰底"⚠︎ 投资人视角"是你写完要自查的坑。
> 一页纸版（Executive Summary）放在最前面，投资人只看这一页决定要不要继续。

---

## 0. 一页纸摘要（最后写，放最前）

- **一句话**：我们为【谁】解决【什么痛苦】，通过【什么方式】赚钱。
- **现状**：【已签约X家客户 / 月流水X万 / 留存X% / 已上线X个月】
- **本轮**：融【金额】，出让【X%】，估值【X】，钱花在【3个用途，各占比】
- **为什么是现在**：【一个正在发生的变化，让这件事以前做不成、现在能做成】

> ⚠︎ 投资人视角：这一页必须能独立读懂。如果删掉后面所有页还讲不清你在干嘛，摘要就没写好。

---

## 1. 问题与痛点

- 目标用户是谁（越具体越好：不是"中小企业"，而是"年营收3000万-1亿的跨境卖家"）
- 他们现在怎么解决这个问题？成本/效率有多差？
- 你亲眼见过多少次这个痛点？（有用户访谈/调研数据更好）

> ⚠︎ 投资人视角：说"市场很大"是废话。要证明"这批人现在正在为此花钱或浪费时间"。

## 2. 解决方案与产品

- 产品是什么，怎么用（关键流程 3 步以内说清）
- 现在到什么阶段：想法 / Demo / 内测 / 已上线 / 有收入
- 技术或模式上的关键壁垒（不是"我们更努力"）
- 已有知识产权、独家资源、牌照等

> ⚠︎ 投资人视角：阶段要诚实。种子期看团队和洞察，A轮后看数据。别把 Demo 说成产品。

## 3. 市场规模

- TAM / SAM / SOM，**必须写清算法**（自上而下 or 自下而上，建议自下而上：客户数 × 客单价）
- 你的数据来源（行业报告名称、年份、链接）

> ⚠︎ 投资人视角：这是最容易被打假的一页。"中国有14亿人所以市场巨大"直接出局。

## 4. 商业模式

- 怎么收费（订阅/抽佣/一次性/广告），客单价多少
- 单位经济模型：CAC（获客成本）、LTV、回本周期、毛利率
- 现在是否已经能验证付费意愿

> ⚠︎ 投资人视角：LTV/CAC < 3 需要解释，毛利为负要有明确转折点。

## 5. 竞争格局

- 直接竞品、间接替代方案（含"用户什么都不做"）
- 一张对比表：维度 × 你 × 竞品A × 竞品B
- 你的差异化，以及**为什么大厂做了你也还活着**

> ⚠︎ 投资人视角：写"我们没有竞争对手"= 要么市场不存在，要么你没做功课。

## 6.  traction（进展与验证）

- 关键指标时间序列：用户数、收入、留存、复购（按月列出）
- 里程碑：签约标杆客户、上线、融资、专利
- 客户证言/案例 1-2 个

> ⚠︎ 投资人视角：数据要能对上。前后页数字不一致是致命伤。

## 7. 团队

- 创始人：为什么是你做这件事（行业年限、做成过什么、踩过什么坑）
- 核心成员：分工 + 相关履历
- 股权结构、全职人数、有没有关键岗位空缺

> ⚠︎ 投资人视角：早期项目投的是人。股权过于平均（5:5）或创始人非全职，会被追问。

## 8. 财务预测（3年）

| 项目 | 今年 | 明年 | 后年 |
|---|---|---|---|
| 收入 | | | |
| 成本 | | | |
| 毛利 | | | |
| 费用 | | | |
| 净利 | | | |
| 用户数 | | | |

- 关键假设写清楚（转化率、客单价、增长率各是多少）
- 历史财务（如有）：过去12个月实际数

> ⚠︎ 投资人视角：预测不是越漂亮越好。要能说出"如果增长只有一半，我们怎么活"。

## 9. 融资需求

- 融【金额】，出让【X%】，投前/投后估值【X】
- 资金用途：产品【%】/ 市场【%】/ 团队【%】，各能换来什么结果
- 这笔钱够跑多少个月（ runway），跑到什么里程碑
- 已有投资人/意向（有背书就写）

> ⚠︎ 投资人视角：说不出"这笔钱买到什么"的融资，会被认为没想清楚。

## 10. 风险与应对

- 主动列 2-3 个真实风险 + 你的应对（政策、竞争、供应链、关键人依赖）

> ⚠︎ 投资人视角：主动说风险反而加分。说"没有风险"是不成熟的表现。
