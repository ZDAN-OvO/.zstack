Judge: 外部判定 = 同一档位冷缓存下的多轮中位数 + 真实 p75 前后对比，且必须交代档位、样本量、是否冷启动；CI 里加一条体积/性能预算断言作为长期守门。方法不过关的结果算不过（缓存预热或样本变小带来的“变快”判失败）。红队单独一轮攻击测量方法本身。
Needs: 首页源码/路由（仓库里没有）、真实 p75 数据或分析后台、可复现的类生产环境或流量回放、设备与网络分布、CDN 与构建配置（vite.config 缺失）、依赖安装。以上除 package.json 外均缺。
