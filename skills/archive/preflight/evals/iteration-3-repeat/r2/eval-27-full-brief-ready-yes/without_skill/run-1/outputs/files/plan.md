# 首页首屏改版 Plan

## 1. 先纠正一个前提

转化率"掉一半"不是文案变差了，是流量结构变了：

| 周 | 访问 | 注册 | 转化 | 主来源 |
|---|---|---|---|---|
| 10-06 | 12,000 | 480 | 4.0% | organic |
| 10-13 | 11,800 | 460 | 3.9% | organic |
| 10-20 | 19,500 | 390 | 2.0% | paid_social |
| 10-27 | 21,000 | 399 | 1.9% | paid_social |

- 访问量 +65%，注册绝对数反而从 480 掉到 390 → organic 那批人大概率还在正常转化，是新增的 paid_social 流量几乎不注册。
- 所以这是"落地页与人群不匹配"问题，不是全站文案退化。**本次只改首屏，不做全站重写**，避免把还在工作的 organic 转化一起改坏。
- 目标换算：paid_social 现在 ~1.9%，回到 3.5% 意味着每周多约 340 个注册。

## 2. 文案要解决的三个具体障碍（来自 support/chats-sample.md）

1. **"我还是没搞懂你们和 Notion 有什么区别"** → 首屏第一句就要回答"我不是 Notion 的替代品/我也是 Notion 的替代品"，不能只讲 "all-in-one workspace"。
2. **"价格页在哪？"** → 首屏给一个可见的价格入口链接（不改定价，只是让入口可见）。
3. **"注册后要连日历，我就放弃了"** → 这是 onboarding 摩擦，文案改不了。**列为本次范围外**，只在 A/B 结果里作为"剩余流失"的解释，另开一单。

## 3. 交付物：3 版首屏（标题 + 副标题）

现版：`The all-in-one platform for modern teams` / `Boost productivity with our seamless, AI-powered workspace.`
→ 完全是品类套话，对"和 Notion 有什么不同"零回答，对社媒引流来的冷流量没有信息量。

**A 版｜对比定位**
- H1：`Notion 管文档，我们管交付`
- Sub：`任务、文档、进度在同一个工作区里连起来。团队不用再在三个工具间同步状态。`
- 主打：差异点直给，最贴聊天里最高频的疑问。

**B 版｜结果导向**
- H1：`让交付按计划发生，而不是按周会`
- Sub：`一个工作区里排期、认领、跟进。上线时间不再靠人肉同步。`
- 主打：付费社媒人群偏"痛点/结果"叙事，比品类词更容易接住。

**C 版｜低门槛试用**
- H1：`不用迁移，先试一个项目`
- Sub：`在现有工具旁边跑一个项目，觉得有用再搬。`
- 主打：拆掉"要不要换掉 Notion"的心理成本；需确认产品真支持并存试用，**若不支持则删掉此版**（不承诺没有的功能）。

> 三版都要带：可见的 `查看价格` 链接；CTA 统一为 `免费开始`。不做弹窗、不改定价页、不承诺路线图功能。

## 4. A/B 方案

- 分流：首页 paid_social 落地流量 50/50，按 visitor_id 稳定分流，不混入 organic。
- 对照：现版首屏（不是空白对照，保证结论可归因）。
- 主指标：注册率（注册数 / 落地 UV）。次指标：价格页点击率、首屏滚动/停留、注册后完成日历连接的比率（用于量化第 2 节的障碍 3）。
- 样本：基线 1.9%、目标 3.5%，80% power / α=0.05 下每臂约需 1,400 UV。按现在 ~21k/周，单臂 1.4k 约 2–3 天可达；**跑满 7 天再判**，避开星期效应。
- 判定：达到 3.5% 且显著 → 全量；1.9%–3.5% 之间不显著 → 取最优版再迭代一轮副标题；≤ 基线 → 回滚，转去查落地页与广告素材/人群的一致性。
- 退路：只保留 H1 改动、副标题回原版，作为最小风险版本。

## 5. 时间线

1. 你从 A/B/C 选 1 版（或指出要保留的句子）→ 我出终稿。
2. 我实现首屏 + 分流埋点（改 index.html，不动其他区块）。
3. 上线跑 7 天 → 我出结果表 + 建议。
4. 并行开单：注册后日历连接摩擦（范围外，单独处理）。

## 6. 不做什么

- 不改定价、不加弹窗、不承诺未上线功能。
- 不重写整页、不动导航和注册流程。
- 不使用网上竞品文案；所有措辞取自 support 聊天里的用户原话。
