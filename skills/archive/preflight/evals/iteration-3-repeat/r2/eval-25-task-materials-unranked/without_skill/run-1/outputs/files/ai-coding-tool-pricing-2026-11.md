## 二、几个会直接影响比价的坑

1. **计费单位不统一**：灵码/Comate/CodeBuddy 是“订阅 + 积分（tokens）额度”，Trae 个人版是积分制，Trae 企业版按“会话用量”，Comate 企业版按“双席位”。横向比“每人每月多少钱”会失真，得先估团队月真实消耗（补全 + Chat + Agent 任务各占多少）。
2. **积分额度差一个量级**：同价位下 Comate ¥59 给 25k 积分、CodeBuddy ¥70 给 4k、Trae ¥99 给 4k —— 积分口径不同，不能直接换算成 token 单价，只能拿团队真实用量试算。
3. **模型资源单独计费**：Comate 企业版 ¥138/双席位 不含模型资源，这块往往才是大头。
4. **促销价到处都是**：限免（灵码专业版）、首月折扣、5.6 折年付、双十一积分包。决策要按**标准价**算，促销当净收益。
5. **企业版价值主要是治理而非功能**：审计日志、SSO、IP 白名单、专有网络、用量管控——如果合规不要求，个人版 + 统一采购往往更便宜（但违反多数厂商个人版商用条款，需确认）。

## 四、询价清单（建议同时发给 4 家）

- 50 / 100 席年付净价，是否含模型额度；超量单价（元/百万 token 或 元/积分）
- 是否支持 VPC / 私有化，最低起订量与实施费
- 是否支持 JetBrains + VS Code 双插件、CLI/Agent 并发上限
- 数据留存与训练使用条款（代码是否出境/被用于训练）、等保/信创要求
- 试用期：能否给 20 人 × 4 周 POC，含用量报表
